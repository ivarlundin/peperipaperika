# CMS mode (Juteströms Bygg)

CMS mode is an alpha editing layer for the labs preview. Normal visitors are unaffected until an editor activates CMS mode.

## Activation

1. Open any page on labs, for example `https://labs.ivarlundin.se/testing/jutestromsbygg/`.
2. Click the discreet **Edit** button in the bottom-right corner (sticky).

The stub in `assets/js/cmsmode-stub.js` lazy-loads `cms-mode.js` and `cms-mode.css`.

## Editing

- **Text:** Hover copy in `main` or the site footer; click to edit inline (`contenteditable`). Press Escape to cancel.
- **Images:** Click an image in `main` or footer. Pick from the manifest built from `assets/img/`. Set alt text in the prompt.

## Panel

Bottom-right panel shows change count, per-change **Ångra** (undo), and **Export changes** (downloads JSON). Changes persist in `localStorage` (`jutestromsbygg-cms-changes-v2`) until undone or cleared.

Build output ships `assets/cms/image-manifest.json` (generated by `scripts/build.py` via `scripts/cms_build.py`).

## Apply changes back to `_src`

1. Review the export JSON.
2. From `_src/jutestromsbygg/`:

```bash
python3 scripts/apply_cms_export.py /path/to/cms-export.json
```

3. Rebuild:

```bash
python3 scripts/build.py --output-dir ../../testing/jutestromsbygg --subpath /testing/jutestromsbygg
```

4. Commit `_src` and `testing/` together.

Always diff before committing; the apply script is best-effort.
