# CMS mode (console WYSIWYG)

CMS mode is an **alpha** editing layer for the Halv Fjorton site on labs. Normal visitors are unaffected until an editor runs `cmsmode()` in the browser console.

## Activation

1. Open any page on the labs preview (for example `https://labs.ivarlundin.se/testing/halfbandnew2026/`).
2. Open DevTools → Console.
3. Run:

```js
cmsmode()
```

The stub in `assets/js/cmsmode-stub.js` lazy-loads `cms-mode.js` and `cms-mode.css`.

## Editing

- **Text:** Hover copy in `main` or the site footer; click to edit inline (`contenteditable`). Press Escape to cancel.
- **Typewriter H1:** Click the animated hero suffix. Animation pauses; edit one phrase per line. Saves to `data-typewriter-phrases` and ghost text.
- **Images:** Click an image in `main` or footer. Pick from the manifest built from `assets/img` (including gallery). Set alt text in the prompt. Srcset variants are applied when available.

## Panel

Bottom-right panel shows change count, per-change **Ångra** (undo), and **Export changes** (downloads JSON). Changes persist in `localStorage` (`halfbandnew2026-cms-changes-v1`) across page loads until undone or cleared.

## Export JSON format

```json
{
  "version": 1,
  "site": "halfbandnew2026",
  "exportedAt": "2026-10-15T12:00:00.000Z",
  "page": "/testing/halfbandnew2026/brollop/",
  "changes": [
    {
      "cmsId": "cms-brollop-t-12",
      "page": "/testing/halfbandnew2026/brollop/",
      "sourceFile": "_src/halfbandnew2026/scripts/build.py",
      "selector": "[data-cms-id=\"cms-brollop-t-12\"]",
      "type": "text",
      "oldValue": "Previous copy",
      "newValue": "Updated copy",
      "meta": { "tag": "p" }
    }
  ]
}
```

| Field | Meaning |
| --- | --- |
| `cmsId` | Stable `data-cms-id` injected at build time |
| `sourceFile` | `_src` file to patch (`home/index.html` or `scripts/build.py`) |
| `type` | `text`, `image`, or `typewriter` |
| `oldValue` / `newValue` | Values for search-replace or review |
| `meta` | Extra data (image manifest id, alt text, typewriter phrase arrays) |

Build output also ships `assets/cms/image-manifest.json` (generated by `scripts/build.py` via `scripts/cms_build.py`).

## Apply changes back to `_src`

1. Review the export JSON.
2. From `_src/halfbandnew2026/`:

```bash
python3 scripts/apply_cms_export.py /path/to/cms-export.json
```

3. Rebuild:

```bash
python3 scripts/build.py --output-dir ../../testing/halfbandnew2026
```

4. Commit `_src` and `testing/` together.

The apply script is best-effort: unique `oldValue` strings work reliably; ambiguous matches are reported on stderr. Always diff before committing.

## Build integration

On each build, after URL rewriting for labs:

- Annotates HTML with `data-cms-id`, `data-cms-type`, and page source metadata on `<body>`.
- Injects `cmsmode-stub.js` before `</body>`.
- Writes `assets/cms/image-manifest.json`.

Do not copy `_src` into `testing/` by hand; use `scripts/build.py` only.
